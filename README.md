# The Silly Cat Slayer

Um jogo 2D feito com Python e Pygame.

## Como baixar e jogar

1. Abra [o repositório no GitHub](https://github.com/jaoandrade/Pygames) e escolha **Code > Download ZIP**.
2. Extraia o ZIP mantendo a pasta `assets` junto dos arquivos do jogo.
3. No Windows, execute `main.exe`.

O executável também está disponível em `main.exe` na página do repositório. Para executar pelo código-fonte, instale Python 3 e rode:

```powershell
python -m pip install -r requirements.txt
python main.py
```

Execute os comandos na pasta do jogo para que os arquivos de `assets` sejam encontrados.

## Controles

- **WASD**: mover
- **Espaço**: disparar uma flecha
- **M**: abrir o menu

## Arquivos

- `main.py`: código-fonte do jogo
- `main.exe`: executável para Windows
- `assets/`: imagens, sprites e sons usados pelo jogo
